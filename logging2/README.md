This is a school course task to test logging.

# Usage

### Initialisation

> npm init -y  
> npm install --save winston@@3.11.0  
> npm install express@4.18.2

and copy or clone the filestructure and files.

### Running the server program main.js

> node src/main.js

A directory logs/ should appear with two .log files.

### Testing the routes offered by the server

Run the HTTP queries from rest.http

### End testing

> Ctrl | commmand + c  

in terminal to kill the server.
